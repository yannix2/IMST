## Architecture in one paragraph

One navigation tree (`src/lib/navigation.ts`) feeds the header menu, phone sheet, footer, breadcrumbs, sitemap and hreflang. Each page is a server component under `app/(site)/[locale]/…` built from a shared `PageShell` (header, metro breadcrumb, page hero with greeting and Hairline figure, footer, phone bar). Page text lives in typed content modules (`src/content/<area>/<page>.ts`, one object per locale), not in `messages.ts`. CMS-backed parts (head's message, FAQ, menu, people, accreditation number) are read through `maarif-api` as on Home, and hide when empty. Interactive parts (staircase, finder card, Hairline figures) are client leaves that load near the viewport; CLS stays 0 and Home's JS stays within budget.
